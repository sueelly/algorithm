<h2><a href="https://www.acmicpc.net/problem/6550">6550번: 부분 문자열</a></h2>
<p><strong>시간 제한:</strong> 1초 | <strong>메모리 제한:</strong> 128MB</p>
<hr>

<h3>문제</h3>
<p>2개의 문자열 s와 t가 주어졌을 때 s가 t의 부분 문자열인지 판단하는 프로그램을 작성하라. 부분 문자열이란 t에서 몇 개의 문자를 제거하고 나머지 문자를 원래 순서대로 합쳐서 s를 만들 수 있는 경우를 말한다.</p>

<h3>입력</h3>
<p>입력은 여러 개의 테스트 케이스로 이루어져 있다. 각 테스트 케이스는 한 줄에 두 문자열 s와 t가 빈칸을 사이에 두고 주어진다. s와 t의 길이는 10만을 넘지 않는다.</p>

<h3>출력</h3>
<p>각 테스트 케이스에 대해 s가 t의 부분 문자열이면 "Yes"를, 아니면 "No"를 한 줄에 하나씩 출력한다.</p>

<h3>예제 입력 1</h3>
<pre>sequence subsequence
person compression
VERDI vivaVittorioEmanueleReDiItalia
caseDoesMatter CaseDoesMatter
</pre>

<h3>예제 출력 1</h3>
<pre>Yes
No
Yes
No
</pre>
