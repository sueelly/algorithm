# 1074. Z

## 문제
[https://www.acmicpc.net/problem/1074](https://www.acmicpc.net/problem/1074)

한수는 크기가 2^N × 2^N인 2차원 배열을 Z모양으로 탐색하려고 한다. 2×2 배열은 왼쪽 위, 오른쪽 위, 왼쪽 아래, 오른쪽 아래 순으로 방문한다.

N > 1인 경우, 배열을 2^(N-1) × 2^(N-1) 크기로 4등분한 뒤 재귀적으로 같은 순서로 방문한다.

### 2×2 Z 순서 (방문 순서 0, 1, 2, 3)

![2×2 Z-order](1074-Z-2x2.png)

### 2²×2² (4×4) Z 순서 (N=2일 때 방문 순서 0~15)

![4×4 Z-order](1074-Z-4x4.png)

N, r, c가 주어졌을 때 (r, c)를 몇 번째로 방문하는지 출력하시오.

## 입력
첫째 줄에 정수 N, r, c가 주어진다. (1 ≤ N ≤ 15, 0 ≤ r, c < 2^N)

## 출력
r행 c열을 몇 번째로 방문했는지 출력한다.

## 예제 입력 1
```
2 3 1
```

## 예제 출력 1
```
11
```

## 예제 입력 2
```
3 7 7
```

## 예제 출력 2
```
63
```

## 예제 입력 3
```
1 0 0
```

## 예제 출력 3
```
0
```
