# 1074번: Z - 코드 리뷰

## 📝 내 Solution.java 분석

```java
public int solve(int n, int r, int c) {
    int answer = 0;
    n = (int) Math.pow(2, n);

    while (n != 1) {
        n >>= 1;

        if (r >= n) {
            answer += 2 * n * n;
            r -= n;
        }
        if (c >= n) {
            c -= n;
            answer += n * n;
        }
    }
    return answer;
}
```

### 접근 방식
- **반복문 분할 정복**: 전체 크기 `size = 2^N`에서 시작해 매번 절반(`n >>= 1`)으로 줄이며, (r, c)가 어느 사분면에 있는지 보고 해당 블록 수만큼 `answer`에 더한 뒤 좌표를 그 구간 안으로 옮김.
- Z 순서: 1사분면(왼쪽 위) → 2사분면(오른쪽 위) → 3사분면(왼쪽 아래) → 4사분면(오른쪽 아래). `r >= n`이면 아래 절반(3 or 4)이므로 `2*n*n` 추가, `c >= n`이면 오른쪽 절반(2 or 4)이므로 `n*n` 추가.
- `r -= n`, `c -= n`으로 다음 단계에서는 현재 사분면을 새로운 전체로 두고 같은 방식 반복.

### 시간 복잡도
- **O(N)** — 반복 횟수 = N (매번 크기가 절반이 되므로)

### 공간 복잡도
- **O(1)** — 변수만 사용, 재귀 스택 없음

### 장점 ✅
1. **재귀 없음** — 스택 오버플로우 걱정 없고, N≤15에서도 일관된 동작
2. **비트 시프트** `n >>= 1`로 나눗셈 대신 사용해 약간의 최적화
3. **공간 O(1)** 로 메모리 효율적

### 개선 가능한 점 💡
1. **초기화**: `Math.pow(2, n)` 대신 `1 << n`으로 통일하면 정수 연산만으로 처리 가능 (부동소수점 이슈 회피).
2. **가독성**: “사분면 오프셋”을 주석으로 적어두면 (1사분면 0, 2사분면 n², 3사분면 2n², 4사분면 3n²) 의도가 더 분명해짐.

## 🏆 대표 풀이

### 방법 1: 재귀 (분할 정복)
```java
public int solve(int n, int r, int c) {
    if (n == 0) return 0;
    int half = 1 << (n - 1);
    int block = half * half;

    if (r < half && c < half) return solve(n - 1, r, c);
    if (r < half && c >= half) return block + solve(n - 1, r, c - half);
    if (r >= half && c < half) return 2 * block + solve(n - 1, r - half, c);
    return 3 * block + solve(n - 1, r - half, c - half);
}
```
- 문제 정의와 1:1로 대응되어 이해하기 쉬움.
- N≤15라 재귀 깊이도 15로 안전.

### 방법 2: 반복문 + 비트만 사용 (현재 코드 개선)
```java
public int solve(int n, int r, int c) {
    int answer = 0;
    int size = 1 << n;  // Math.pow 대신

    while (size != 1) {
        size >>= 1;
        if (r >= size) { answer += 2 * size * size; r -= size; }
        if (c >= size) { answer += size * size;   c -= size; }
    }
    return answer;
}
```

### 내 코드와의 차이점
| 항목 | 내 코드 | 재귀 풀이 | 비트만 반복 |
|------|---------|-----------|-------------|
| 방식 | 반복 + Math.pow | 재귀 | 반복 + 시프트 |
| 공간 | O(1) | O(N) 스택 | O(1) |
| 가독성 | ⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| 초기값 | Math.pow(2,n) | 1<<(n-1) | 1<<n |

**결론**: 논리는 동일. `Math.pow` → `1 << n`으로 바꾸면 정수만 쓰게 되어 더 안정적.

## 💡 학습 포인트

### 1. Z 순서 = 사분면 번호로 오프셋
- 1사분면: +0
- 2사분면: + block (block = half²)
- 3사분면: + 2*block
- 4사분면: + 3*block  
한 번에 “지나친 칸 수”만 더하고, 해당 사분면 안에서 같은 문제를 반복하면 됨.

### 2. 반복문으로 바꾸는 요령
- “현재 (r,c)가 지금 구간의 어디에 있는지”만 보면 됨.
- `half`(또는 size/2)보다 크면 오른쪽/아래 절반이므로 오프셋을 더하고, 좌표에서 half를 빼서 다음 단계로 넘김.

### 3. 비트 연산
- `1 << n` = 2^n (n ≥ 0)
- `n >>= 1` = n/2 (정수)
